# English project reports

These reports present the three phases of the Charging Station Management System (CSMS) course project. Each phase is a self-contained English document, with related diagrams, editable models and interface references linked alongside the text.

| Phase | Main report | Coverage |
| --- | --- | --- |
| 1 | [Requirements and operational analysis](phase-1-requirements.md) | Business context, stakeholders, comparable-system study, five workflows, requirements and technical planning |
| 2 | [System analysis and UML modeling](phase-2-system-modeling.md) | Use cases, activities, domain classes and sequences for lifecycle, session and fault workflows |
| 3 | [User experience and acceptance specifications](phase-3-ux-design.md) | Workflow personas, 17 user stories, acceptance criteria, design system and desktop/mobile prototypes |

The [Persian source collection](../fa/INDEX.md) remains available as supplementary material. Prototype interface labels are Persian; their workflow explanations and acceptance specifications are provided in English here.
