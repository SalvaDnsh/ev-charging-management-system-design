# متن و واحدهای رابط کاربری

| بخش | برچسب | متن راهنما |
| --- | --- | --- |
| ثبت ایستگاه | ظرفیت برق (کیلووات) | ظرفیت برق ایستگاه را بر حسب کیلووات وارد کنید |
| ثبت کانکتور | شناسهٔ داخلی کانکتور | شناسه داخلی کانکتور را وارد کنید |
| انتخاب نقش | عنوان سامانه | سامانه مدیریت ایستگاه‌های شارژ خودرو برقی |

اطلاعات رسید نشست در سطرهای مستقل نمایش داده می‌شوند: شناسهٔ نشست، نتیجه و علت پایان، انرژی بر حسب کیلووات‌ساعت، مدت بر حسب دقیقه و هزینه بر حسب ریال. متن در عرض کارت قرار می‌گیرد و ارتفاع کارت متناسب با محتواست.
