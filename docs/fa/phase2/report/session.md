# جریان کاری: مدیریت نشست شارژ<sup><a href="#fn-1-6578" id="fnref-1-6578">1</a></sup>

## معرفی جریان کاری

جریان مدیریت نشست شارژ یکی از سه جریان کاری اصلی فاز دوم پروژه است که هدف این فرآیند، مدیریت کامل چرخه یک نشست شارژ از آغاز تا پایان و ایجاد داده های قابل اعتماد برای کنترل عملیات، محاسبه هزینه، تحلیل عملکرد و ارزیابی کیفیت سرویس است. در این صفحه چهار نمودار استاندارد شامل، نمودار مورد کاربرد<sup><a href="#fn-2-6578" id="fnref-2-6578">2</a></sup>، نمودار کلاس<sup><a href="#fn-3-6578" id="fnref-3-6578">3</a></sup>، نمودار فعالیت<sup><a href="#fn-4-6578" id="fnref-4-6578">4</a></sup> و نمودار توالی<sup><a href="#fn-5-6578" id="fnref-5-6578">5</a></sup> به همراه توضیحات تحلیلی هر یک ارائه شده است.
